# 🍱 오늘 뭐 먹지? | MenuPicker 랜덤 메뉴 추천기

결정 장애 완벽 해결사! 매일 점심, 저녁마다 "오늘 뭐 먹지?" 고민될 때 재미있는 슬롯머신 룰렛으로 메뉴를 추천받으세요.

![MenuPicker](/menu-picker/index.html)

## ✨ 주요 기능

- **🎰 재미있는 슬롯머신 애니메이션 & 효과음**:
  - 버튼 클릭 시 또르르르 룰렛이 돌며 팡파레와 함께 랜덤 메뉴를 선출합니다.
  - Canvas Confetti로 신나는 당첨 효과 제공.
- **🏷️ 카테고리 필터링**:
  - 전체, 🍲 한식, 🇨🇳 중식, 🍣 일식, 🍕 양식, 떡볶이 분식, 🍰 디저트/카페별로 골라서 뽑기 가능.
- **🗺️ 맛집 검색 & 배달 앱 바로가기**:
  - 당첨된 메뉴를 클릭 한 번으로 네이버 지도 검색 및 배달 서비스 연동 검색.
- **➕ 나만의 메뉴 관리**:
  - 원하는 음식을 자유롭게 추가/삭제할 수 있으며 브라우저(LocalStorage)에 자동 저장.
- **📜 최근 뽑은 메뉴 히스토리**:
  - 최근 추천받은 음식 기록 확인 가능.
- **🎨 모던 UI & 다크 모드**:
  - Tailwind CSS, Glassmorphic UI 디자인 및 음소거/테마 변경 지원.

## 🚀 실행 방법

```bash
# 로컬에서 바로 실행 (macOS 예시)
open menu-picker/index.html
```
